# digiTools Platform
   A modern digital tools marketplace

## Features
  - Dynamic product listing fetched using Axios.
  - Toggle view between 3-column Product Grid and 1-column Cart view.
  - Real-Time add too cart, Remove Item, and Clear Cart on Checkout with Toastify notification.
  - Vizual sales chart analytics using Recharts.

## Tech Stack
  - React.js, Tailwind CSS (v4), DaisyUI (v5)
  - Lucide React, React Icons
  - Axios, Rechart, React-Toastify
